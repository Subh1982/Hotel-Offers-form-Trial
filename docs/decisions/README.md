# Architecture Decision Records

Use this directory for durable decisions that explain why the application is designed a particular way.

Create files named `NNNN-short-title.md` with this structure:

```md
# NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Owners: role or team, not personal credentials

## Context

What problem and constraints led to the decision?

## Decision

What was chosen?

## Consequences

What becomes easier, harder, or operationally important?

## Alternatives considered

What credible alternatives were rejected, and why?
```

Do not rewrite accepted records to hide history. Add a superseding record and link the two.
